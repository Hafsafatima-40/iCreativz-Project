# 🔥 FORGE – Interval Training Timer

**interval training · precision timing**

---

## 🎯 About

FORGE is a professional web-based interval training timer for HIIT, circuit training, and precision timing workouts. Built with vanilla HTML, CSS, and JavaScript – zero dependencies, runs offline.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| ⏱️ **Simple Mode** | Set workout duration, rest time, and number of rounds |
| 📋 **Custom Mode** | Build and save your own exercise sequences |
| 🔊 **4 Alarm Sounds** | Standard Beep, Loud Alarm, Police Siren, Air Horn |
| ⚠️ **Warning Beeps** | Audible alerts during final seconds |
| 📊 **Progress Bar** | Real-time visual tracking |
| 💾 **LocalStorage** | Custom routines persist after browser close |
| 🎨 **Dark Theme** | Professional, bold, modern UI |
| 📱 **Responsive** | Works on desktop, tablet, and mobile |

---

## 🛠️ Technologies Used

- **HTML5** – Structure
- **CSS3** – Styling, animations, dark theme
- **JavaScript ES6+** – Timer logic, event handling
- **Web Audio API** – Sound generation
- **LocalStorage API** – Data persistence

---

## 🚀 How to Use

1. Click **Enable Audio** (required for sound)
2. Choose **Simple** or **Custom** mode
3. Adjust your settings
4. Select your preferred **Alarm Sound**
5. Click **Start** and begin your workout
